# 수족관 — 기획서

작성: 2026-09-25 · 대상 버전: v2.1(1차, **구현됨**) / v2.2(2차) · 상위 문서: [GDD.md](GDD.md)

코드: 데이터·가격 `aquarium-data.js`, 화면·그리기 `game.js`의 `수족관` 절, 팝업 `index.html`의 `#aq-*`.

## 0. 왜 만드는가

- 성장 비용 전체(조개 약 97,300 + 보석 17)가 1~2시간 플레이면 끝난다(시뮬레이션 추정, 누적 판매 기준으로는 실측과 일치 — 심해 도달 시 누적 약 6~7만).
- 심해 풀강 수입은 시간당 약 15만(여유)~27만(연속) 조개로 추정된다. 이 조개를 쓸 곳이 없다.
- 출시 후라 기존 가격·확률은 건드리지 않는다. **기존 곡선은 도입부로 두고, 그 위에 수입을 늘리지 않는 소비처를 얹는다.**

### 설계 원칙

1. **수입을 늘리지 않는다.** 수족관의 어떤 요소도 판매가·확률·릴링에 영향을 주지 않는다. 보상은 전시·외형뿐이다.
2. **잔잔함 유지.** 타이머·먹이 주기·물 갈기 같은 관리 의무가 없다. 들어가서 보기만 해도 된다.
3. **파일 0개 원칙 유지.** 수조·장식은 캔버스 프로시저럴, 물고기는 기존 어종 SVG를 그대로 쓴다.
4. **이미 쌓인 잔고를 흡수할 만큼 넓게.** 랭킹 1위 누적 판매 약 100만 기준으로도 첫날에 다 사지 못하는 총액.

## 1. 결정 사항

| 항목 | 결정 |
|---|---|
| 진입 | 낚시터 팝업 목록 맨 아래 **수족관 카드** → 상세 시트 → 입장. 캔버스 전체가 수조 장면으로 바뀐다 |
| 해금 | **바다 해금 후** 카드가 열린다. 입장은 무료, 수조는 구입 |
| 전시 방식 | **보관함의 잡은 개체를 옮긴다.** 옮긴 물고기는 팔 수 없고, 꺼내면 놓아주기(사라짐). 되팔기 없음. 첫 넣기에만 확인창 |
| 수조 | 낚시터별 3개(민물·바다·심해). 각 수조에는 그 낚시터 어종만 들어간다 |
| 같은 종 중복 | 허용 (작은 물고기 떼를 만들 수 있게) |

## 2. 코어 루프 (수족관)

```
낚시 → 보관함 ──┬─ 판매 → 조개 ──┬─ 수조 구입·확장
               │                └─ 장식 구입·배치
               └─ 전시 (판매 포기) → 수조 감상 → "이 종도 넣고 싶다" → 낚시
```

- 목표: 수조마다 **24종 전부 전시**(일반 10·희귀 7·특급 4·전설 3). 칸을 24까지 늘려야 가능하다.
- 전설 3종을 전시하려면 전설을 잡아서 팔지 않아야 한다 → 전설 미끼(뽑기)의 새 용도.

## 3. 경제 ★

### 3-1. 소비처 가격표

**수조 구입** (한 번)

| 수조 | 조건 | 가격 |
|---|---|---|
| 민물 수조 | 바다 해금 | 5,000 |
| 바다 수조 | 바다 해금 | 30,000 |
| 심해 수조 | 심해 해금 | 100,000 |

**칸 확장** — 기본 3칸 → 6 → 10 → 15 → 20 → 24칸 (5단계). 기준가 × 수조 배율(민물 ×1 · 바다 ×2 · 심해 ×4).

| 단계 | 칸 | 기준가 (민물) | 바다 | 심해 |
|---|---|---|---|---|
| 1 | 3 → 6 | 5,000 | 10,000 | 20,000 |
| 2 | 6 → 10 | 15,000 | 30,000 | 60,000 |
| 3 | 10 → 15 | 40,000 | 80,000 | 160,000 |
| 4 | 15 → 20 | 100,000 | 200,000 | 400,000 |
| 5 | 20 → 24 | 200,000 | 400,000 | 800,000 |
| 합계 | | 360,000 | 720,000 | 1,440,000 |

**장식** — 수조마다 같은 구성, 기준가 × 수조 배율(민물 ×1 · 바다 ×1.5 · 심해 ×2). 각 분류의 첫 항목은 기본(무료).

| 분류 | 구성 (기본 제외) | 기준가 합 |
|---|---|---|
| 바닥재 | 일반 5,000 · 희귀 20,000 | 25,000 |
| 배경 | 희귀 20,000 · 특급 60,000 | 80,000 |
| 조명 | 일반 5,000 · 희귀 20,000 | 25,000 |
| 소품 (v2.2) | 일반 5,000 ×3 · 희귀 20,000 ×3 · 특급 60,000 · 전설 200,000 + 보석 10 | 335,000 |
| 합계 | | 465,000 |

### 3-2. 총액과 목표 시간

| 묶음 | 조개 | 보석 |
|---|---|---|
| 수조 구입 | 135,000 | — |
| 칸 확장 | 2,520,000 | — |
| 바닥재·배경·조명 (v2.1) | 585,000 | — |
| 소품 (v2.2) | 1,507,500 | 30 |
| **전체** | **4,747,500** | **30** |

- 심해 풀강 기준 약 **17시간(연속)~32시간(여유)** 분량 (수입 추정치 기준, 실측 보정 필요).
- 바다 막 해금한 유저(시간당 약 5.6만, 여유): 민물 수조 + 1단계 확장 + 장식 1~2개 ≈ 2만 → 약 20분. 첫 체험은 빠르게, 뒤는 길게.
- 랭킹 1위(누적 약 100만, 잔고 상한 약 90만)도 v2.1 분량(324만)의 1/3 이하만 즉시 살 수 있다.
- 전시로 포기하는 판매가(기회비용)는 위 총액에 포함하지 않았다. 수조 3개 × 24종 완성 기준 대략 수십만 규모(전설 비중에 따라 다름).

### 3-3. 재화 흐름 변경

```
조개 ──┬──▶ (기존) 낚싯대·능력치·뽑기·낚시터
       ├──▶ 수조 구입 · 칸 확장        ← 신규
       └──▶ 장식                       ← 신규
보석 ──┬──▶ (기존) 낚싯대 등급업
       └──▶ 전설 소품 (v2.2)           ← 신규
물고기 ─┬─▶ 판매
        └─▶ 전시 (영구, 판매 불가)      ← 신규
```

- **v2.2 보석 드랍 재개**: 지금은 특급 낚싯대가 되면 보석이 안 떨어진다(`rollGem()`). 전설 소품용으로 특급 이후에도 6%를 유지한다. 수입(조개)은 늘지 않으므로 원칙 1과 충돌하지 않는다.
- **랭킹**: 전시한 물고기는 판매가 아니므로 누적 판매 점수에 들어가지 않는다. **(2026-09-25 결정: 반영하지 않음)**

## 4. 화면

```
낚시터 팝업
 ├─ 호수 / 바다 / 심해 카드 (기존)
 └─ 수족관 카드 (신규, 바다 해금 전: 잠김 "바다를 해금하면 열려요")
      └─ 상세 시트 → [입장]  (낚시 중 불가, 기존 이동 규칙과 동일)

수족관 모드 (캔버스 = 수조 장면)
 ├─ 상단바: [수족관 ▸ 낚시터 팝업] [조개] [보석]   ← 기존 레이아웃 그대로, 라벨만 교체
 ├─ 수조 칩: 민물 · 바다 · 심해 (안 산 수조는 "구입" 표시)
 ├─ 캔버스: 물고기 탭 → 이름·크기 말풍선
 ├─ 하단 바 (수족관 전용 3칸): 전시 | 꾸미기 | 낚시하러 가기
 └─ 팝업
     ├─ 전시 (탭: 넣기 / 수조 안, 위에 칸 수 + [N칸으로 늘리기])
     │    ├─ 넣기: 보관함 중 이 수조 낚시터 물고기(등급·크기 순)
     │    │    └─ 첫 넣기만 확인: "수조에 넣은 물고기는 팔 수 없어요…"
     │    └─ 수조 안: 전시 목록, [놓아주기] (매번 확인창)
     └─ 꾸미기 (탭: 바닥재 / 배경 / 조명 / 소품)
          └─ 카드: 미리보기 색 · 이름 · 가격 · [구입] / [적용] / 적용 중
```

- 낚시용 하단 탭 5개는 수족관 모드 동안 숨기고, 수족관 전용 바로 교체한다. 탭 상한 규칙(5개)을 어기지 않는다.
- **알림** (한 번만): 수족관이 열린 뒤 첫 한가한 순간(낚시·팝업·튜토리얼·타이틀이 없을 때)에 "수족관이 열렸어요" 카드 [나중에 / 보러가기]. 기존 유저는 업데이트 후 첫 실행, 신규 유저는 바다 해금 직후. 한 번도 들어가지 않은 동안은 상단 낚시터 버튼에 빨간 점, 수족관 카드에 NEW 배지. 스스로 먼저 들어가면 카드는 뜨지 않는다.
- 소품 배치는 자유 드래그 없이 **수조당 고정 5자리**(바닥 좌·중·우, 뒤 좌·우)에 넣는 방식. 한 손 세로 조작 기준.
- 낚시하러 가기 / 시스템 뒤로가기 → 마지막 낚시터로 돌아간다(`stage`는 수족관 동안 바뀌지 않는다). 수족관 안에서의 뒤로가기는 종료 확인창을 띄우지 않는다.
- 낚시터 팝업의 다른 낚시터 카드로 바로 이동해도 수족관을 빠져나간다.

## 5. 연출

- **수조 장면**: 유리 테두리 + 물 그라데이션(수조 테마 색) + 바닥재 층 + 배경 층 + 조명(전체 색조 오버레이·빛줄기). 기존 `drawLightShafts`, `fillWaterGradient`, 물결선 재사용.
- **물고기**: 어종 SVG를 `Image`로 캔버스에 그린다. 아이콘은 **왼쪽을 향하므로** 오른쪽으로 헤엄칠 때 좌우 반전.
  - 크기: `px = 28 + (110 − 28) × (ln(cm) − ln 3) / (ln 1500 − ln 3)` — 송사리(3cm) 28px, 리바이어던(1,500cm) 110px. 같은 종도 잡은 크기 차이가 보인다.
  - 움직임: 수조 안에서 목표점을 골라 천천히 이동 → 도착하면 새 목표. 등급이 높을수록 느리고 크게. 전설은 은은한 발광.
- **소리**: 수조 테마의 낚시터 BGM을 그대로 쓴다(1.5초 크로스페이드 재사용). 효과음은 넣기(물방울)·구입(coin)만.

### 세이브 스키마 12 → 13

```
aquarium: {
  tanks: {                      // 산 수조만 키가 생긴다
    lake: {
      cap: 0,                   // 확장 단계 0~5 (칸 = [3,6,10,15,20,24][cap])
      fish: [ { uid, id, tier, size } ],   // caughtFish에서 옮겨온 개체
      floor: 'lake_floor_0', back: 'lake_back_0', light: 'lake_light_0',
      props: [null, null, null, null, null]  // v2.2
    }
  },
  decor: [],                    // 산 장식 id (기본 장식은 저장 안 함)
  putHintSeen: false, introSeen: false, visited: false
}
```

- 마이그레이션 12→13: 빈 `aquarium`(위 기본값) 추가만. 다른 필드는 그대로 통과.
- 넣기 = `caughtFish`에서 splice → `tanks[st].fish`에 push → `persist()`. 한 번의 저장으로 끝나서 중간 상태가 남지 않는다.
- `putHintSeen`: 첫 넣기 확인창을 봤는지. `introSeen`: 알림 카드를 띄웠는지. `visited`: 한 번이라도 들어갔는지(점·NEW 배지). 로드 시 `normalizeAquarium()`이 모르는 장식 id·어종을 걸러낸다.
- `stage` 필드가 없는 옛 보관함 물고기는 어종 id로 낚시터를 찾는다.
- 데이터 삭제는 세이브 전체를 지우므로 추가 처리 불필요.
